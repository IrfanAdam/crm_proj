## Motion posture

Subtle and state-clarifying: elastic funnel settle on scroll, timeline scrub
reshaping the funnel live, tilt-depth on funnel detail cards. Honor
`prefers-reduced-motion` (static end-state, no elastic loop).

## 3D rewards (existing build — keep)

Single Spline gem + capsule stand, recolored per category via CSS hue-rotate
filters (guardrails §4). Ceremony copy pattern: `Rock Solid Goals` /
`+Rs 4lakh / Closed Beyond Your Target / on 23rd Oct`. Gems never appear in
Operate/Monitor chrome.

## Mood direction (brand surfaces only)

- Frosted-glass orbs + pink/purple/blue gradient spheres; editorial voice
  (`Bubble. Doesn't have the mind borders / Stand Out / Break Layout`).
- Iridescent-cube brand surface; ALPHA voice
  (`Only CRM stack you need / data in here don't lie`).
- Constraint: this decoration lives in brand, onboarding, and ceremony
  surfaces — never inside Operate/Monitor screens, which stay flat and quiet.

## Guardrails

- Motion explains state; nothing loops without purpose.
- One gem asset, four filters — never four models.
- New mood refs enter via `../references/REGISTRY.md` intake, not direct edits.
