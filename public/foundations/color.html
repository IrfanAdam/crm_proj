Chapter 2 · Foundations · 01 Color

One hue acts. The rest celebrate.

Every screen answers one question — what do I do next? Color answers it with a single hue: Sapphire. Citrine, red beryl, amethyst and green are gem hues: earned, celebratory, never structural. If two hues ever compete for one tap, the screen is wrong.

  • 01

    Sapphire is the sole action hue — every tap, link and selected state.

    Reject: a second action hue anywhere — teal buttons beside sapphire ones.

  • 02

    Gems never do chrome — rewards, streaks and scores only.

    Reject: an amethyst header, a citrine nav background, a ruby button.

  • 03

    Roles, not hues, in code — components reference --role-*, never primitives.

    Reject: a component pointing at --primitive-sapphire-ui-500 — the signal swap would silently break it.

  • 04

    Signal swap-slot — --signal re-tints the whole app: default, amber, teal.

    Reject: an action hex hard-coded outside tokens/.
