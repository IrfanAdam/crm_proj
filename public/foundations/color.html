Roles — what code may touch (Law 03)

One shape per role: role.name ships soft (−200) · base · strong (+100) · ink, and ink is the only text colour allowed on its base. Families follow the playground — Neutral the brand action, Core the gem hues, Messaging feedback. Ratios are measured; roles are theme-stable. Code spells the same name with dashes: role.action.soft → --role-action-soft.
