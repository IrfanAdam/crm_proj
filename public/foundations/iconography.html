Chapter 2 · Foundations · 07 Iconography

Regular walks. Fill is chosen.

One set — Phosphor — six weights, one voice. Regular 1.5px is the resting state; fill plus Sapphire plus a dot marks the chosen one. The dock stays neutral glass: the icon carries the signal, never the background. Sizes step 12 to 32, and nothing else.

  • 01

    One set only — Phosphor Regular and Fill. No mixing with legacy sprite glyphs.

    Reject: a one-off custom SVG that "felt more precise" — the set is the voice.

  • 02

    Fill means chosen — selected tab: fill glyph, signal color, dot above.

    Reject: fill without the dot, or color without fill — the selected state is all three.

  • 03

    Unselected is secondary, never dim — text.secondary keeps every glyph legible.

    Reject: dim or muted unselected icons — resting is not fading.

  • 04

    Sizes step 12 → 32 — icon.size.xs–xl, nothing between.

    Reject: a 22px icon eyeballed into place — the dock uses lg, the reason is documented.

Variants — six weights, one family

Every glyph ships in all six weights at the same codepoint — weight is a class swap (ph → ph-bold), never a different icon. Pages load all six stylesheets so any weight renders anywhere.

WeightVoiceWhen
thinhairlinehero illustration, empty-state backdrops at 32+ — never chrome, too fragile at 16
lightdisplaylarge display 24+, marketing surfaces — never dense rows
regularresting UIevery unselected glyph in chrome — the default voice
boldemphasis12–16px sizes where regular starves; emphasis without fill
fillchosenselected tab only, with signal + dot — never decoration
duotonetwo-tonefeature illustration, onboarding — secondary layer at 20%; never status, reads as decoration
