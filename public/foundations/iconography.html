Regular walks. Fill is chosen.

One set — Phosphor — six weights, one voice. Regular 1.5px is the resting state; fill plus Sapphire plus a dot marks the chosen one. The dock stays neutral glass: the icon carries the signal, never the background. Sizes step 12 to 32, and nothing else.

  • 01

    One set only — Phosphor Regular and Fill. No mixing with legacy sprite glyphs.

    Reject: a one-off custom SVG that "felt more precise" — the set is the voice.

  • 02

    Fill means chosen — selected tab: fill glyph, signal color, dot above.

    Reject: fill without the dot, or color without fill — the selected state is all three.

  • 03

    Unselected is secondary, never dim — text.secondary keeps every glyph legible.

    Reject: dim or muted unselected icons — resting is not fading.

  • 04

    Sizes step 12 → 32 — icon.size.xs–xl, nothing between.

    Reject: a 22px icon eyeballed into place — the dock uses lg, the reason is documented.

ADAM derivatives — diamond-cut · gem-friendly · same weight API, distinctly different cuts

Plain ph-diamond = 4-edge rhombus. ph-diamonds-four = Sketch-like cluster. diamond-cut = outer rhombus + table + 4 spokes = faceted gem. gem-friendly = the ph-sketch-logo silhouette re-cut with friendly edges — rounded table corners, girdle bulges and culet, flat top, girdle line, two continuous facet seams. All six weights (thin 1 / light 1.2 / regular 1.5 / bold 2 / fill / duotone) inherit currentColor — API identical to Phosphor: <Icon name="gem-friendly" size={20} weight="regular" />

Derivatives — sketch-logo playground set

ADAM derivatives of the Sketch-like cluster. sketch-cut = outer frame + 4 mini-diamonds + central table (cluster-cut) — distinctly different from ph-diamonds-four (4 isolated diamonds) but still reads as a diamond cluster. diamond-cut = single faceted gem (table + spokes). gem-friendly = the ph-sketch-logo gem with friendlier edges: rounded table corners, girdle bulges and culet; seam tops at 0.44·W and girdle landings at 0.31·W (the logo's own facet ratios), feet joined at the outline apex (0.848·H) — the gem to reach for when representing rewards. The library glyph itself is also wired for the gem role: sketch-logo / gem = ph-sketch-logo as shipped (the flat diamond symbol; Sketch's wordmark is a separate mark). All three cuts share the Phosphor API: thin 1 / light 1.2 / regular 1.5 / bold 2 / fill / duotone + currentColor → <Icon name="gem-friendly" weight="regular" />. Mirrors the playground controls above — search sketch, diamond-cut, gem-friendly or sketch-logo, switch weight, drag size.
