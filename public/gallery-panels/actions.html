With icons — leading + icon-only

Anatomy — 44px frame · label · icon · spinner. Label never wraps; icon-only is square and needs aria-label. Reject: a button that changes width when loading starts.

Spec · anatomy

44px frame holds size across variants with a transparent 1px border; optional leading .btn__icon; loading swaps in .btn__spinner without moving the frame. Glyphs: Icon only — see Identity.

Sizes — sm / md / lg

Density — btn--sm / md / lg map to 32 / 44 / 48px frames, xs / sm / md type. md and up keep the 44px minimum target.

States — disabled / aria-disabled / loading / focus

Link button

States speak before words do — hover deepens one step, active one more, focus always rings (Tab for the 2px ring). Loading holds the frame and announces aria-busy. Reject: grey-on-grey with no ring.
