Spec — emphasis ladder

Emphasis is a ladder, not a palette — primary → secondary → tonal → ghost. Sapphire acts; red destroys only. Try every step live in the playground above. Reject: two primaries side by side, or a shadow added to "pop".

Spec — anatomy + density

44px frame holds size across variants with a transparent 1px border; optional leading .btn__icon; loading swaps in .btn__spinner without moving the frame. btn--sm / md / lg map to 32 / 44 / 48px frames, xs / sm / md type — md and up keep the 44px target. Label never wraps; icon-only is square and needs aria-label.

Spec — states + a11y

States speak before words do — hover deepens one step, active one more, focus always rings (Tab for the 2px ring). Loading holds the frame and announces aria-busy. Tune every state live above; the Aa badge reports the live pair. Reject: grey-on-grey with no ring.

Spec — contract

Form / sheet commitment — full-width stretches, label centered. Do: one primary per row, hold the frame while loading. Don't: shadow to "pop", ghost a primary, wrap the label.
