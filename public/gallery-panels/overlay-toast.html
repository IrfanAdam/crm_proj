Spec — toast regions + tones

Transient confirm of a past act — always topmost, rises in over --transition-spring, dwells, pauses on hover, sinks out.

Spec — anatomy

.toast-region is fixed, .toast is a flex row — message + optional .toast__action (semibold, citrine) + .toast__close (✕, subtle). Dark surface --primitive-neutral-dark-700, white ink, flex gap --spacing-3.

Spec — states + a11y

Visible = opacity 1 translate 0; closing sinks back. Dwell 4s default, 8s with an action, hover pauses dwell via stopDwell/startDwell. Never takes focus.

Spec — contract

Use after saves and completes — never for critical errors alone, never steals focus, stack floats below modals in DOM but above via --z-index-toast.
