Spec — menu anchors + density

Anchored action list from a trigger — one column, no icons-only, one level deep. Opens under its trigger and flips to fit.

Spec — anatomy

.menu is an absolute list, .menu__item rows with --spacing-2 gaps. Selected rows get .menu__item--selected (bg-interactive). A separator uses .menu__separator.

Spec — states + a11y

Opens with fade + scale over --transition-fast; Esc or a select or an outside click dismisses and refocuses the trigger. Arrows rove items, Home/End jump, no tab trap.

Spec — contract

Use for Assign / Rename / Archive rows and toolbar overflows. Dialog over menu when the choice needs a confirm.
