Spec — anatomy

.tooltip is absolute, single line by default, padded --spacing-1 vertical + --spacing-2 horizontal, xs type, pointer-events none, sits above the trigger via the .ov-anchor.

Spec — states + a11y

Hidden by default; hover or focus-within shows with opacity 1 after --motion-duration-xs delay; Esc dismisses. Never focusable, never traps.

Tokens --primitive-neutral-dark-700 / --primitive-gray-white / --radius-sm / --z-index-modal / --transition-fast. A11y role=tooltip + aria-describedby, never the only name, pointer-events none.

Spec — contract

Use to name an icon-only button or clarify a label. Never a tooltip holding buttons or as the sole name.
