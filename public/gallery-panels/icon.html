Spec — sizes · token only, no custom

Five sizes — xs 12 to xl 32 — cover prefixes to hero glyphs. md 20 is the base with no modifier. Any off-scale size is a spec violation.

Spec — anatomy + density

.icon frame is inline-flex centered; svg fills 100% and inherits currentColor. Weight is set via Icon.jsx weight prop or CDN ph-thin / ph-fill class. Gap to text is spacing.1–2 from parent; icon never sets its own margin.

Spec — states + a11y

Icon has no hover/active/disabled — the control owns it. Decorative stays aria-hidden; semantic exposes an accessible name via control or role="img" + aria-label. Fill marks selected; bold marks high emphasis.

Spec — contract

One foundry — Phosphor only. Do: registry via Icon.jsx, inherit currentColor, reserve fill for selected. Don't: sprite.svg in new work, hand-swapped svg, off-scale sizes.
