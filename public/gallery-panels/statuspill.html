Spec — anatomy + density

Full pill with transparent 1px border, leading status-pill__icon (Phosphor 12px) or status-pill__dot (currentColor 8px) then uppercase label. --sm tightens pad to spacing.1 / 2; base is 6px vertical. Label never wraps.

Spec — states + a11y

Plain pills have no hover; --clickable adds pointer + opacity.subtle hover and is the only state with hover. Focus always rings 2px sapphire; disabled dims via opacity.disabled.
