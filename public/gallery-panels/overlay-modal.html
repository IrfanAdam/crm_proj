Spec — modal sizes + placement

Blocking confirm only — one primary action. Width locks to the content card, not the scrim. Top sheets, center modals, bottom sheets all share the same trap and return-focus.

Spec — anatomy

Scrim (.overlay) owns the inset and the --achievement-overlay-bg wash; .overlay__content owns radius, shadow, and padding. Header rows title + close, body is one paragraph, footer right-aligns actions. The card never grows beyond 85vh.

Spec — states + a11y

Open = scrim fade + content rise over --transition-fast; closing adds .is-closing to opacity 0 then hidden. Persistent ignores scrim + Esc and needs an explicit close.

Spec — contract

Use for deletes and confirms only. Drawer over modal for filters and long forms. Never nest modal-on-modal.
