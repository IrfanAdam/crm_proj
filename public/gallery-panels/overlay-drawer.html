Spec — drawer sides + widths

Context panel — keeps the page behind visible, slides in to hold filters and long-form work. Pick the narrowest width that fits the form.

Widths clamp to 85vw (wide to 100%) — never wider than --wide.

Spec — anatomy

.drawer is a fixed-height flex column — header pins up, .overlay__body scrolls, .overlay__footer sticks with a top rule. The same header/body/footer tokens as modals, but pinned in a column.

Spec — states + a11y

Open slides in over --transition-spring; closing rides the same curve back; reduced-motion snaps. Dismissible drawers trap like modals; persistent ones don't.

Tokens --bg-surface / --border-thin / --shadow-lg / --z-index-modal / --focus-ring. A11y Esc, Tab wrap when dismissible, return-focus, background inert when trapping.

Spec — contract

Use for filter rails and long forms where context matters. Modal over drawer for one-question confirms.
