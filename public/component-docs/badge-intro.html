Components · Identity · 03 Badge

Counts beside things. Never things themselves.

Badge is the count glyph beside a label or pinned to an object — inbox totals, row counts, a dot of presence. It annotates; it never acts, filters, or carries meaning alone. Use it when a number clarifies scale; reach for Chip when the tap filters, StatusPill when it flags a stage.

  • 01

    Anatomy — pill · bold micro count · tinted fill. Tinted fill with darker ink and hairline border via primitive.sapphire-ui / green / orange / red + radius.full + spacing.1–2; bare 8px badge--dot omits text; badge--max caps at 99+ with tabular-nums.

    Reject: an exact 4-digit count — cap at 99+, never let the pill grow.

  • 02

    Static only — never interactive. No hover, active, focus, or disabled; the anchor (button, row, avatar) owns interaction and focus. The badge inherits context state and never promises an action.

    Reject: a focusable or clickable badge — the anchor owns interaction.

  • 03

    Overlap draws its own ring. badge-wrap (relative anchor) + badge--overlap pins top-right via translate(50%,-50%); the pill border is the separation ring — no extra halo token exists; five tones are closed.

    Reject: a sixth tone — map every count to neutral / success / warning / danger / brand.
