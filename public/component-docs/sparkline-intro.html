Components · Data · 05 Sparkline

A gesture of momentum. Never chrome.

Sparkline is momentum in bars: gem hues only, no axes, no labels. It gestures at direction; it never charts precisely. Use it when a glance suffices; use a real chart when values matter.

  • 01

    Anatomy — bars · accent · peak. Base bars in amethyst 300, --accent 500 marks the climb, --gem 700 crowns the peak; sparkline--stroke draws outline bars for overlays.

    Reject: an unmarked run — always crown the peak with accent or gem.

  • 02

    Gem hues stay quarantined. Amethyst bars live only here — never as chrome fills, never as text ink. Stroke style is a transparent fill with a medium amethyst-400 ring, open at the bottom.

    Reject: gem bars outside viz — the quarantine gate holds.

  • 03

    Decorative or labelled, decided up front. Decorative bars hide behind aria-hidden with a data fallback beside them; semantic ones take role=img plus a trend label.

    Reject: silent semantic bars — a trend without a label says nothing to AT.
