Components · Data · 03 KpiStat

One headline number. Signed direction.

KpiStat is the headline metric: value plus total plus delta — the 4/32 closed +2%. It states the number; it never explains it. Use it when a trio tells the story; use Sparkline when momentum needs a gesture.

  • 01

    Anatomy — value · total · delta · spark. __value headline, __total muted scope, __delta signed chip, __spark trailing slot right-aligned on the baseline.

    Reject: a second delta — one direction chip per KPI, never two.

  • 02

    Delta ink passes, tint never speaks alone. Up is green 700 on green 100, down is red 700 on red 100 — the tone-on-tone wash that failed AA now follows the badge ink scale.

    Reject: unsigned or tint-only deltas — the sign and the 700-step ink carry meaning.

  • 03

    Sizes scale the number, never drop the total. kpi--sm compacts to md value, kpi--lg opens to 2xl value with md total; the trio stays in order at every size.

    Reject: a lonely value — value/total/delta stay together in that order.

Snippet — the contract in code

Do

Keep value/total/delta in that order. Sign the delta. Let the spark slot sit trailing on the baseline.

Don't

Never add a second delta. Never use the delta chip outside a KPI. Never drop the total at small sizes.

Accessibility — the non-negotiables

The trio must read as one sentence to assistive tech — value, total, then signed delta — with delta never carried by color alone.
