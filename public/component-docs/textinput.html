Components · Form · 03 TextInput

Labelled single lines. Never naked placeholders.

TextInput is single-line entry — names, amounts, emails. One md frame at 44px, label above, help or error below. It captures values; it never offers choices (Select), never filters (Search), never holds paragraphs (Textarea).

  • 01

    Anatomy — field · label · wrap · input · affix · help. .field columns with spacing.2 gap; xs uppercase .field__label; relative .field__wrap anchoring absolute 16px .field__prefix / .field__suffix slots (₹/L, icon, action); xs meta below.

    Reject: an input with no label — placeholder text never names the field.

  • 02

    States speak in tokens, never bare hue. Error is a role.danger border with aria-invalid + aria-describedby to the error id; success swaps in role.success; focus is sapphire-400 plus the focus.ring shadow, on :focus not only keyboard.

    Reject: a second error hue, or an error carried by color alone.

  • 03

    Sizes and skins stay on the scale. sm 32px, md 44px, lg 48px; --filled is the dense interactive wash; affix padding reserves calc(spacing.3 + icon-size.sm + spacing.2) so ₹ never collides with ink.

    Reject: a shrunk md frame — 44px is the touch target, not a suggestion.

Snippet — the contract in code

<label class="field__label" for="amt">Amount</label> <div class="field__wrap"><span class="field__prefix">₹</span><input id="amt" class="field__input field__input--with-prefix field__input--with-suffix field__input--error" aria-invalid="true" aria-describedby="amt-err"><span class="field__suffix">L</span></div> <p id="amt-err" class="field__error">Enter an amount in lakhs.</p>
Do

Keep every input labelled. Put errors in .field__error with aria-describedby, icon plus text. Hold md at 44px. Say why near any disabled field.

Don't

Never use placeholder as the label. Never invent a second error hue. Never let an affix collide with the value.

Accessibility — the non-negotiables

Label association (for or wrapped) · error sets aria-invalid + aria-describedby · success/error never color-alone (icon + text) · md frame meets the 44px target · muted and danger ink gated by contrast tests · forced-colors restores a CanvasText outline · reduced-motion still.
