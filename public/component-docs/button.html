Snippet — the contract in code

<button class="btn btn--primary" data-loading>Save deal</button> <button class="btn btn--ghost btn--icon-only" aria-label="Close">…</button>
Do

Keep one primary per row. Keep sapphire the sole action hue. Hold the frame while loading. Explain disabled with aria-disabled where the reason matters.

Don't

Never shadow a button to "pop". Never ghost a primary action. Never wrap the label. Never invent a hue for emphasis.

Accessibility — the non-negotiables

44px minimum target on md and up · native <button> semantics, links stay links · visible focus ring always · loading sets aria-busy · white on sapphire-500 clears AA (gated in tests/contrast.test.mjs) · forced-colors falls back to ButtonFace/ButtonText.
