Components · Choice · 01 Checkbox

Many independent on-offs. Never instant settings.

Checkbox is the multi-select control: 0..n independent on/offs in a list or form, bulk select, confirmations. It answers to a submit; it never takes instant effect. Use it when each option stands alone; use Switch for instant settings, Radio for one-of-n.

  • 01

    Anatomy — label · input · box · tick. label.check wraps a native input[type=checkbox] (absolute, transparent, still focusable) + .check__box (20px, rounded) + .check__icon tick (SVG scales 0.6 to 1) + .check__label text.

    Reject: a div-faked box with no native input — proxies never intercept pointer or keyboard.

  • 02

    Sizes and partial state. check--sm (16px) / default (20px) / check--lg (24px); partial-group "select all" uses native input:indeterminate, set via el.indeterminate = true in JS.

    Reject: indeterminate used as a third value — it means partial group only.

  • 03

    Focus is the shared ring law. input:focus-visible + .check__box paints box-shadow: var(--focus-ring) (2px sapphire ring); paint uses var(--transition-fast), reduced-motion kills it.

    Reject: a custom glow or outline — focus is always the shared ring token.

Snippet — the contract in code

<label class="check"><input type="checkbox"><span class="check__box"><svg class="check__icon"></svg></span><span class="check__label">Email me</span></label> <label class="check check--sm check--error"><input type="checkbox" aria-invalid="true"><span class="check__box"><svg class="check__icon"></svg></span><span class="check__label">Required</span></label>
Do

Wrap the input in the label. Use indeterminate only for partial groups. Keep label text always visible on a 44px row.

Don't

Never fake with divs. Never shrink below 16px. Never put two checkboxes on one label. Never use for instant settings.

Accessibility — the non-negotiables

Native input[type=checkbox] · Space toggles · aria-checked="mixed" only on custom proxies · label always visible · shared focus ring · 44px row · forced-colors maps fill to Highlight.
