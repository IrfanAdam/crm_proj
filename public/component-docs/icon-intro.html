Components · Identity · 06 Icon

Phosphor only. Decorative until named.

Icon is the Phosphor-only glyph system — registry via Icon.jsx plus sprite.svg fallback and CDN ph classes, currentColor, token sizes. Regular 1.5px stroke by default; fill marks selected. Use it when an action or signal needs a glyph; reach for Avatar when the mark is a person.

  • 01

    Anatomy — icon frame · Phosphor svg at 100% · size modifier. Frame inherits context color; svg fills edge to edge; five sizes xs 12px to xl 32px via icon-size.xs / sm / md / lg / xl; base md 20px with no modifier.

    Reject: any glyph outside the Phosphor registry — one foundry only.

  • 02

    Weight means state. Regular default; fill marks selected; bold is high-emphasis only. Applied via Icon.jsx weight prop or ph-fill / ph-bold — never a hand-swapped svg.

    Reject: fill weight as decoration — fill always answers selection.

  • 03

    Static — it inherits, never owns state. No hover, active, or disabled of its own; the surrounding control owns interaction. icon--muted (text.muted) and icon--subtle (text.dim) step hierarchy, not meaning.

    Reject: an off-scale size — xs–xl or nothing.
