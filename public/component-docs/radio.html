Components · Choice · 02 Radio

Exactly one of n. Never a lone boolean.

Radio is the exclusive-choice control: 2–7 visible options where options need comparison text. One shared name, one checked at a time, a sane default pre-selected. Use it when choice is exclusive; use Checkbox for multi-select, Switch for instant settings.

  • 01

    Anatomy — group · label · dot. fieldset.radio-group (+ legend) holds label.radio rows: native input[type=radio][name=shared] + .radio__dot (20px circle, inner ::after dot at 50% scaling 0.6 to 1) + .radio__label.

    Reject: radios without a shared name or without fieldset + legend — a group must read as a group.

  • 02

    Groups lay out two ways. radio-group--vertical is the default (tight gap); radio-group--horizontal is a wrapping row (wide gap) for short options on wide screens.

    Reject: horizontal layout on narrow screens — stack when space runs out.

  • 03

    Focus is the shared ring law. input:focus-visible + .radio__dot paints box-shadow: var(--focus-ring); checked is an accent ring plus a scaling dot, never hue alone.

    Reject: checked signalled by color without the dot — selection must survive no-color rendering.

Snippet — the contract in code

<fieldset class="radio-group radio-group--vertical"><legend>Plan</legend> <label class="radio"><input type="radio" name="plan" checked><span class="radio__dot"></span><span class="radio__label">Team</span></label> <label class="radio radio--error"><input type="radio" name="plan" aria-invalid="true"><span class="radio__dot"></span><span class="radio__label">Custom</span></label></fieldset>
Do

Share one name per group. Use fieldset + legend. Pre-select a sane default. Describe group help and errors.

Don't

Never mix radios and checkboxes in one group. Never offer a single-option group. Never disable all options without help text.

Accessibility — the non-negotiables

Native same-name radios · arrows move and select, Space selects · Tab enters the group once · aria-describedby for help and error · visible focus ring · 44px rows · forced-colors safe.
