Components · Overlays · 01 Layers

Interrupt with intent. Never stack surprises.

Overlays float six layers — modal, drawer, menu, tooltip, popover, toast — served by one engine: single focus-trap, Esc-to-close, return-focus. Each layer has one job and one alternative; stacking reuses tokens, never raw z-index.

  • 01

    When, or its alternative. Modal blocks for confirms; drawer keeps context for filters and long forms; menu lists actions; tooltip names one thing; popover anchors rich panels; toast confirms past acts. Drawer over modal-for-forms, toast-plus-undo over modal-for-trivia.

    Reject: a modal for filter panels or a tooltip holding buttons — right layer or no layer.

  • 02

    Trap, Esc, return. Modal and dismissible drawer trap Tab, close on Esc (unless .overlay--persistent), and return focus to the opener; menus and popovers close-and-refocus without trapping. Toasts never take focus at all.

    Reject: a trap that strands focus or an Esc that does nothing — every layer gives focus back.

  • 03

    Tokens stack, DOM orders. Floats sit on --z-index-dropdown (in-dialog: --z-index-modal), scrim --z-index-overlay, dialogs --z-index-modal, toasts always --z-index-toast. Later dialogs paint above by DOM order; tooltips never trap, toasts always win.

    Reject: raw z-index numbers or nested modal-on-modal — restack in order, never invent depth.

Snippet — the contract in code

<div class="overlay overlay--open"><div class="overlay__content overlay__content--md" role="dialog" aria-modal="true" aria-labelledby="t1"> <div class="overlay__header"><h2 class="overlay__title" id="t1">Delete deal?</h2></div> <div class="toast-region" aria-live="polite"><div class="toast toast--visible" role="status">Saved</div></div>
Do

Pick the lightest layer that does the job. Trap and return focus on dialogs. Announce toasts via live regions, never focus.

Don't

Never nest modals, auto-open on load, or full-screen except --full. Never put critical errors only in a toast.

Accessibility — the non-negotiables

Dialogs: labelledby/describedby, focus in on open, Tab wrap, Esc, return-focus, background inert · menus: roving arrows · tooltips: describedby, Esc, never focusable · toasts: role=status (alert for danger), container aria-live, action Tab-reachable, no focus steal.
