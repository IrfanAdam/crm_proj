Components · Choice · 04 Slider

Draggable quantity. Never a hidden value.

Slider is the quantity control: continuous amounts (volume, price cap) or stepped amounts with visible stops. The value benefits from drag plus tick labels, and the value is always shown. Use it when amount matters; use Radio for 2–4 named options, text input for exact entry.

  • 01

    Anatomy — input · track · thumb · ticks. input[type=range].slider (full-width 6px track) + ::-webkit-slider-thumb / ::-moz-range-thumb (20px face, medium-width accent ring, grab cursor) + ::-moz-range-track / ::-moz-range-progress fill + optional .slider__ticks row.

    Reject: styling one vendor engine only — webkit and moz thumbs ship together.

  • 02

    Continuous or discrete, never vague. Continuous is the default; slider--discrete adds native step, a repeating-gradient tick strip, and .slider__ticks labels. slider--sm (16px) / --lg (24px) resize the thumb.

    Reject: discrete steps without native step, or step and tick counts that disagree.

  • 03

    Dragging keeps the ring. :active switches the cursor to grabbing while the shared var(--focus-ring) persists on the thumb; hover lifts to a medium shadow.

    Reject: error shown by color alone — danger paint always ships with text.

Snippet — the contract in code

<input type="range" class="slider" min="0" max="100" value="40" aria-valuetext="40 percent"> <input type="range" class="slider slider--discrete slider--lg" min="1" max="10" step="1" value="4"><div class="slider__ticks"><span>1</span><span>10</span></div>
Do

Pair with a live value readout. Match step and tick counts. Keep tick labels short. Keep thumbs 16px or larger.

Don't

Never hide the value. Never build discrete steps without native step. Never use for binary choice.

Accessibility — the non-negotiables

Native input[type=range] with min/max/step/value · aria-valuetext ("75 percent, high") · arrows step, PgUp/PgDn, Home/End · aria-invalid plus described error · visible thumb ring · full-width track · reduced-motion safe.
