Components · Data · 02 ListRow

One line per opportunity. Nothing more.

ListRow is the one-line opportunity: logo, name, meta, end slot. It navigates to the record; it never compares columns. Use it when rows open something; use Table when rows compare.

  • 01

    Anatomy — logo · main · end. __logo 32px tile, __main with ellipsized __name plus __meta, __end right column stacking Badge over __time.

    Reject: a wrapping name — the name ellipsizes, always.

  • 02

    End slot composes, never crowds. Badge carries the state hue, __time carries plain text beside it; the column stays right-aligned and stacked.

    Reject: badge-alone meaning — hue plus time text, never hue by itself.

  • 03

    Selection means picked, not hovered. list-row--selected pairs the active wash with a sapphire border; hover wash alone never claims current.

    Reject: selection where rows only navigate — select only the current row.
