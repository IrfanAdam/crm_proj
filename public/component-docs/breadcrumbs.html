Components · Navigation · 02 Breadcrumbs

Where you are. Never where to go next.

Breadcrumbs show the trail back — workspace, list, record. They orient and offer retreat; they never drive the next action. Use them on depth 2+ pages; omit them where Tabs already name the context.

  • 01

    Anatomy — nav · list · current. nav aria-label="Breadcrumb" holds an ol; separators (/ or ·) carry aria-hidden="true". The current page is .breadcrumbs__current with aria-current="page" — never a link.

    Reject: a linked current page — arrival is a fact, not a destination.

  • 02

    Collapse the middle, keep the ends. .breadcrumbs--collapsed hides .breadcrumbs__item--collapsible behind a .breadcrumbs__collapse (…) button; expanded shows the full trail. Home and current never collapse.

    Reject: hiding the current page to save room — collapse the middle, never the answer.

  • 03

    Truncate long labels, not the trail. .breadcrumbs__item--truncated ellipsizes past --spacing-16 with full text on title. The structure stays complete while the ink stays short.

    Reject: a crumb pushing siblings off-screen — long labels end in …, never in overflow.

Snippet — the contract in code

<nav class="breadcrumbs" aria-label="Breadcrumb"><ol> <li class="breadcrumbs__item"><a href="/deals">Deals</a></li> <li class="breadcrumbs__item"><span class="breadcrumbs__current" aria-current="page">Acme</span></li></ol></nav>
Do

Mark the current page with aria-current and plain text. Hide separators from assistive tech. Keep the collapse button 44px.

Don't

Never link the current page. Never collapse home or current. Never expose separators to screen readers.

Accessibility — the non-negotiables

Landmark nav with aria-label · aria-current="page" on plain-text current · hidden separators · 44px collapsed toggle · visible focus ring.
