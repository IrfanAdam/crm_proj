Components · Navigation · 05 TabBar

Three icons home. Never a fourth wheel.

TabBar is the mobile dock — icon-only Phosphor glyphs with 44px+ targets that jump between top-level homes. It docks and signals; it never labels. At three or fewer tabs it supersedes Tabs — never render both.

  • 01

    Icon-only dock, fat targets. Glyphs only, no labels; each .tabbar__item clears 44px (--spacing-10 min) inside a --bg-surface-glass bar. Active state is .tabbar__item--active mirrored by aria-current="page".

    Reject: labelled dock items or sub-44px targets — the dock is thumb-first, text-free.

  • 02

    One signal dot, ever. A single .tabbar__signal dot in --role-action sits on the active item only. Counts live in the separate .tabbar__badge pill (--role-score), omitted at zero — badge and signal never read as two dots.

    Reject: a badge plus a signal dot on one item — one item, one mark.

  • 03

    Three tabs kill the tab row. At ≤3 tabs on mobile the dock supersedes Tabs for the same views. Two switchers for one set is disorientation with extra steps.

    Reject: dock and tab row side by side — pick the dock, drop the row.

Snippet — the contract in code

<nav class="tabbar" role="tablist" aria-label="Primary"> <button class="tabbar__item tabbar__item--active" aria-current="page" aria-label="Deals">◆<span class="tabbar__signal"></span></button> <button class="tabbar__item" aria-label="Inbox">◆<span class="tabbar__badge">3</span></button></nav>
Do

Keep icons labelless with aria-labels. Show one signal dot on the active item. Drop Tabs when the dock takes over.

Don't

Never pair badge and signal as twins. Never ship sub-44px targets. Never depend on motion to show state.

Accessibility — the non-negotiables

Tablist semantics · aria-current mirrors active · icon aria-labels · forced-colors fallback · state never carried by motion alone.
