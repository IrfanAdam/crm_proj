Components · Actions · 01 Button

One primary per row. Never a second.

Button carries the row's single high-emphasis action — the tap the whole row exists for. Everything else in the row steps down to secondary, tonal, or ghost. Use it when the user commits, advances, or confirms; reach for a chip when they filter, a link when they navigate away.

  • 01

    Anatomy — frame · label · icon · spinner. 44px frame holds size across variants with a transparent 1px border; label never wraps; optional leading .btn__icon; loading swaps in .btn__spinner without moving the frame.

    Reject: a button that changes width when it starts loading — layout shift reads as breakage.

  • 02

    Emphasis is a ladder, not a palette. Primary → secondary → tonal → ghost → danger-ghost, each step quieter. Sapphire stays the sole action hue; red appears only where data is destroyed.

    Reject: two primaries side by side, or a shadow added to "pop" — elevation never sells emphasis.

  • 03

    States speak before words do. Hover deepens one step, active one more; focus always rings; disabled dims to opacity.disabled and drops the pointer; loading holds the frame and announces aria-busy.

    Reject: grey text on grey fill with no ring — a keyboard user must always see where they are.
