Snippet — the contract in code

<button class="chip chip--selected" data-toggle aria-pressed="true">Value range</button> <button class="chip chip--input" data-toggle>Economic <span class="chip__count">4</span></button>
Do

Use pills for countable, filterable facets. Reserve hot chrome for the live streak. Announce pressed state to assistive tech. Let Delete remove input chips.

Don't

Never commit a flow from a chip. Never tint chips with gem hues. Never leave selection to color alone. Never wrap the label.

Accessibility — the non-negotiables

Native <button> semantics · aria-pressed mirrors selection · Delete/Backspace removes focused input chips · 44px target on faces facets · visible focus ring · forced-colors keeps the selected inversion.
