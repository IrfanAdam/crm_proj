Components · Cards · 02 FunnelCard

Pipeline health at a glance. Never a metric dump.

FunnelCard is the pipeline summary: glyph tile, title with refresh stamp, metric strip. It answers "how is the funnel" in one look; detail lives elsewhere.

  • 01

    Anatomy — glyph · title · stamp · strip. 48px __glyph tile, __title plus Last Refreshed __meta, __metrics row of __metric chips. Nothing else joins the frame.

    Reject: a metric rendered outside the strip — CR/RR/CSAT/NPS live only in __metrics.

  • 02

    Glyph stays sapphire, stays decorative. Funnel is the measure family visual — sapphire tile, never a gem celebration hue — and it carries no meaning assistive tech must hear.

    Reject: a gem-hued glyph — ceremony chrome never marks measurement.

  • 03

    Hairline frame, static posture. border.thin on surface, zero shadow; the card is static — no hover lift, no press state.

    Reject: an interactive treatment on the frame — the strip reads, it never acts.

Snippet — the contract in code

<div class="funnel-card"><div class="funnel-card__glyph" aria-hidden="true">…</div> <div class="funnel-card__title">Pipeline</div><div class="funnel-card__meta">Last Refreshed …</div> <div class="funnel-card__metrics"><span class="funnel-card__metric">CR 24%</span></div></div>
Do

Keep the glyph sapphire and decorative. Keep every metric inside the strip. Keep the stamp next to the title.

Don't

Never gem-tint the glyph. Never scatter metrics outside the strip. Never shadow the frame.

Accessibility — the non-negotiables

Glyph is decorative (aria-hidden) · metric values are plain text, never color-only · stamp is readable text · static card takes no focus.
