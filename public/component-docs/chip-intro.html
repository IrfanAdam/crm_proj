Components · Identity · 02 Chip

Filterable facets. Never commitments.

Chip is the Opps filter row: countable facets the user toggles — stages, ranges, people. It selects and deselects; it never advances a flow. Use it when a tap narrows what is shown; use Button when a tap does something.

  • 01

    Anatomy — pill · label · count · close. Full-pill frame, label first, optional .chip__count for the number, optional .chip__close on removable input chips. Faces variants carry a mini-stack instead.

    Reject: a chip with no visible selected state — toggling must always answer back.

  • 02

    Four types, four jobs (Material 3). Filter chips toggle facets; assist chips act on what's shown; input chips represent something removable (Delete key removes); suggestion chips offer a next try. One row mixes types only when each keeps its own job.

    Reject: a suggestion chip styled as selected — suggestions propose, they never claim state.

  • 03

    Selected is unmistakable. chip--selected inverts to near-black fill with white ink; unselected stays surface with a hairline border. Pressed state must be announced — sync aria-pressed wherever JS toggles the class.

    Reject: selected signalled by hue alone — gem hues never do chip chrome.
