Components · Navigation · 02 Breadcrumbs

Where you are. Never where to go next.

Breadcrumbs show the trail back — workspace, list, record. They orient and offer retreat; they never drive the next action. Use them on depth 2+ pages; omit them where Tabs already name the context.

  • 01

    Anatomy — nav · list · current. nav aria-label="Breadcrumb" holds an ol; separators carry aria-hidden="true". Current is .breadcrumbs__current with aria-current="page" — never a link.

    Reject: a linked current page — arrival is a fact, not a destination.

  • 02

    Collapse the middle, keep the ends. .breadcrumbs--collapsed hides .breadcrumbs__item--collapsible behind a .breadcrumbs__collapse (…) button; Home and current never collapse.

    Reject: hiding current to save room — collapse the middle, never the answer.

  • 03

    Truncate long labels, not the trail. .breadcrumbs__item--truncated ellipsizes past --spacing-16 with full text on title. Structure stays complete while ink stays short.

    Reject: a crumb pushing siblings off-screen — long labels end in …, never in overflow.
