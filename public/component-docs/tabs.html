Snippet — the contract in code

<div class="tabs" role="tablist" aria-label="Deal views"> <button class="tab__trigger tab__trigger--active" role="tab" aria-selected="true" tabindex="0">Pipeline</button> <button class="tab__trigger" role="tab" aria-selected="false" tabindex="-1">Activity</button></div>
Do

Keep one tab stop with arrow-key travel. Scroll the row on narrow widths. Mirror active class and aria-selected.

Don't

Never render Tabs beside a TabBar for the same views. Never wrap labels. Never leave disabled tabs arrow-reachable.

Accessibility — the non-negotiables

Tablist semantics · roving tabindex with Arrow/Home/End travel · aria-selected mirrors the active class · labelled panels · visible focus ring.
