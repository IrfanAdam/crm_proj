Components · Form · 04 Select

Native lists. Never faked dropdowns.

Select holds 4+ mutually exclusive options where the current value stays visible — Stage from Prospecting to Closed. It keeps the native select for free keyboard and mobile sheets; ≤3 options is Radio, multi is Checkbox, text suggestions is Search with a listbox.

  • 01

    Anatomy — anchor · native input · chevron · option. .select relative anchor; native .select__input at 44px / radius.md with right pad for the 16px .select__chevron (pointer-events:none); option inherits surface wash and primary ink in both themes.

    Reject: a div-faked select — native semantics are the feature.

  • 02

    The chevron answers the open. :focus-within tints the chevron role.action and rotates it 180° — the CSS proxy for open, since native select exposes none; reduced-motion flips instantly with no animation.

    Reject: a hidden chevron, or a pill select — pill is Search-only.

  • 03

    Frames and states map 1:1 to TextInput. Outlined default, --filled, sm 32px / lg 48px; hover deepens, focus rings sapphire, error and success swap the outline — same tokens, same widths, same offsets.

    Reject: a select skin that drifts from the input scale.

Snippet — the contract in code

<label class="field__label" for="stage">Stage</label> <div class="select"><select id="stage" class="select__input"><option>Prospecting</option><option>Closed</option></select><i class="ph-bold ph-caret-down select__chevron" aria-hidden="true"></i></div>
Do

Keep the native select. Name it with aria-label or .field__label. Let option inherit surface and ink. Announce errors exactly like TextInput.

Don't

Never fake a select with divs. Never hide the chevron. Never ship a pill select.

Accessibility — the non-negotiables

Native semantics announce options + count · chevron aria-hidden · 44px frame · aria-invalid + aria-describedby on error · visible focus ring with forced-colors CanvasText fallback · reduced-motion flips the chevron instantly.
