Components · Navigation · 06 Toolbar

Actions in formation. Never a spill.

Toolbar lines up record and list actions — create, filter, sort, overflow. It groups and compresses; it never lets labels shove actions off-screen. Use groups with dividers; collapse excess into overflow on narrow widths.

  • 01

    Density sets the frame. Default 44px, .toolbar--comfortable 56px, .toolbar--compact --spacing-8 with tight gaps. Density changes rhythm, never which actions exist.

    Reject: compact dropping actions — density compresses spacing, not capability.

  • 02

    Groups divide, spacers push. .toolbar__group clusters kin; adjacent groups split on --border-default divider. .toolbar__spacer shoves trailing actions right while title ellipsizes.

    Reject: undifferentiated soup — group kin, divide strangers, pin the tail.

  • 03

    Overflow catches the spill. Excess .toolbar__actions collapse into .toolbar__overflow menu button on narrow widths. Nothing falls off-screen; everything stays one tap away.

    Reject: actions clipped past the edge — what doesn't fit joins the menu.
