Components · Form · 05 Search

Pill filters. Never data capture.

Search filters and finds within the dataset — opportunities, list rows — with a clear action. It is the 44px pill affordance for filtering; labelled capture is TextInput, navigation is links and tabs, and ⏎ submits while clear resets.

  • 01

    One pill, no sizes. .search__input is always radius.full at 44px with left pad for the 16px leading .search__icon; sm/lg are intentionally absent — search is always the filter affordance.

    Reject: a 12px-radius search, or help text stuffed inside the pill.

  • 02

    Clear only when there is text. The 24px round .search__clear sits on an interactive wash, hovers to primary ink on the active wash, and takes a sapphire width-medium :focus-visible outline — a real button with an accessible name.

    Reject: a permanent clear on an empty field, or a clear no keyboard can reach.

  • 03

    Loading and verdicts stay honest. search--loading spins the icon (motion-duration.md, linear, infinite, cursor stays text) with aria-busy; --error / --success borders mark no-results and applied-filter states, counts announced via live region.

    Reject: a spin with no reduced-motion stop, or silence when results land.

Snippet — the contract in code

<div class="search"><i class="ph-bold ph-magnifying-glass search__icon" aria-hidden="true"></i><input class="search__input" type="search" aria-label="Search opportunities" placeholder="Search opportunities"><button class="search__clear" aria-label="Clear"><i class="ph-bold ph-x" aria-hidden="true"></i></button></div> <p role="status" class="meta">6 results</p>
Do

Show clear only when there is text. Keep the pill. Announce result counts via a live region. Hold the text cursor while loading.

Don't

Never use search as a generic input. Never put help text inside the pill. Never ship a 12px search.

Accessibility — the non-negotiables

Labelled input (for / wrapped / aria-label) · icon aria-hidden · clear is a real button named Clear (24px visual inside the 44px field) · loading sets aria-busy · role="status" count line · forced-colors outline · reduced-motion stops the spin.
