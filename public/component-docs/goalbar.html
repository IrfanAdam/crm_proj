Components · Cards · 04 GoalBar

Temporal fill. Never a ceremony leak.

GoalBar is the D/W/M/Q/Y goal fill: label-left, value-right, time on top, width-% fill in a pill track. Operate chrome by default; the gem variant is quarantined to ceremony.

  • 01

    Anatomy — track · fill · label + value. Pill track (goal-bar), __fill at width %, __label left and __value right overlaid. Time granularity sits above, never inside.

    Reject: restating the value beside the bar — label-left/value-right is the whole readout.

  • 02

    Gem is quarantined. goal-bar--gem (amethyst-700 + ◇ mark) lives only in ceremony; Operate chrome never borrows it and it never appears beside operate fills.

    Reject: --gem outside ceremony — gem hues stay behind the quarantine gate.

  • 03

    Fill is a progressbar with an exit. Live fills carry role=progressbar + aria-valuenow; width animates on transition.spring and surrenders to reduced-motion.

    Reject: animating the fill with no reduced-motion fallback — motion is earned, never forced.

Snippet — the contract in code

<div class="goal-bar"><span class="goal-bar__label">Week</span> <div class="goal-bar__fill" role="progressbar" aria-valuenow="60" aria-label="Week goal" style="width:60%"> <span class="goal-bar__value">60%</span></div></div>
Do

Keep label-left/value-right. Small fill labels belong on strong (white on amethyst-500 AA). Announce live fills.

Don't

Never use --gem outside ceremony. Never restate the value beside the bar. Never animate past reduced-motion.

Accessibility — the non-negotiables

Live fill needs role=progressbar + aria-valuenow + aria-label · white on amethyst-400 is large/bold-only (4.14), small labels go on strong · reduced-motion jumps instantly.
