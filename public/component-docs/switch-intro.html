Components · Choice · 03 Switch

Instant effect on toggle. Never submit-gated.

Switch is the instant binary setting: notifications, dark mode, availability — the effect applies on toggle and reverses inline. Use it when flipping takes effect now; use Checkbox for anything Review-then-Submit, Radio for exclusive choice.

  • 01

    Anatomy — label · track · thumb · icon. label.switch wraps input[type=checkbox][role=switch] + .switch__track (44 by 26, full pill) + .switch__thumb (20px, travels 18px via translate) + optional .switch__icon + .switch__label.

    Reject: a thumb animated by anything but the spring token — travel is always the spring.

  • 02

    Two faces, one track. Without icon is the default; with icon nests .switch__icon in the thumb, fading in only when on. switch--sm shrinks to a 36 by 22 track, 16px thumb, 14px travel.

    Reject: icon-only with no text label — the governed thing must be named.

  • 03

    Focus is the shared ring law. input:focus-visible + .switch__track paints box-shadow: var(--focus-ring); off presses to the active wash, on presses to action-strong, so pressed never equals focus.

    Reject: pressed styled the same as focus — the two must read apart.
