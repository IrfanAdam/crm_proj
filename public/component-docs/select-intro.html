Components · Form · 04 Select

Native lists. Never faked dropdowns.

Select holds 4+ mutually exclusive options where the current value stays visible — Stage from Prospecting to Closed. Native select keeps keyboard and mobile sheets free; ≤3 options is Radio, multi is Checkbox, suggestions is Search.

  • 01

    Anatomy — anchor · native input · chevron · option. .select relative anchor; native .select__input at 44px / radius.md with right pad for the 16px .select__chevron (pointer-events:none); option inherits surface and primary ink.

    Reject: a div-faked select — native semantics are the feature.

  • 02

    The chevron answers the open. :focus-within tints the chevron role.action and rotates 180° — CSS proxy for open since native exposes none; reduced-motion flips instantly.

    Reject: a hidden chevron, or a pill select — pill is Search-only.

  • 03

    Frames map 1:1 to TextInput. Outlined default, --filled wash, sm 32px / lg 48px; hover deepens, focus rings sapphire, error and success swap the outline — same tokens, same widths.

    Reject: a select skin that drifts from the input scale.
