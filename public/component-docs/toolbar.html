Components · Navigation · 06 Toolbar

Actions in formation. Never a spill.

Toolbar lines up record and list actions — create, filter, sort, overflow. It groups and compresses; it never lets labels shove actions off-screen. Use groups with dividers; collapse excess into overflow on narrow widths.

  • 01

    Density sets the frame. Default 44px, .toolbar--comfortable 56px, .toolbar--compact tightens to --spacing-8 with tight gaps. Density changes rhythm, never which actions exist.

    Reject: compact mode dropping actions — density compresses spacing, not capability.

  • 02

    Groups divide, spacers push. .toolbar__group clusters kin; adjacent groups split on a --border-default divider. .toolbar__spacer shoves trailing actions right while .toolbar__title ellipsizes without shrinking the cluster.

    Reject: an undifferentiated action soup — group kin, divide strangers, pin the tail.

  • 03

    Overflow catches the spill. Excess .toolbar__actions collapse into a .toolbar__overflow menu button on narrow widths. Nothing falls off-screen; everything stays one tap away.

    Reject: actions clipped past the edge — what doesn't fit joins the menu.

Snippet — the contract in code

<div class="toolbar" role="toolbar" aria-label="Deal actions"> <div class="toolbar__group" aria-label="Create">…</div><div class="toolbar__spacer"></div> <button class="toolbar__overflow" aria-haspopup="menu" aria-expanded="false">⋯</button></div>
Do

Group kin actions with labelled groups. Ellipsize the title, never the cluster. Keep overflow keyboard-reachable.

Don't

Never let labels push actions off-screen. Never drop actions to fit density. Never strand overflow from the keyboard.

Accessibility — the non-negotiables

role=toolbar + aria-label · grouped aria-labels · keyboard-reachable overflow menu · visible focus ring per action.
