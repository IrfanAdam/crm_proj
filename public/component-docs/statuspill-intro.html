Components · Identity · 04 StatusPill

Stage flags. Never color alone.

StatusPill is the record stage flag — Accepted, In Progress, Review, New, Warning, Danger. Solid fill, uppercase micro label, optional icon or dot. The label carries meaning in every state; hue never works solo. Use it when a row needs stage truth; reach for Badge when it needs a count, Chip when it needs a filter.

  • 01

    Anatomy — pill · optional prefix · uppercase micro. Leading status-pill__icon (icon-size.xs Phosphor) or status-pill__dot (currentColor) then uppercase label; radius.full + font-tracking.wide + font-size.xs semibold.

    Reject: a status told by hue alone — label (and prefix) must be present.

  • 02

    Static by default — hover only when clickable. Plain pills have no hover; status-pill--clickable adds opacity.subtle hover + pointer; focus rings primitive.sapphire-ui-400; disabled dims via opacity.disabled.

    Reject: hover on a non-clickable pill — motion must not promise action.

  • 03

    Six hues, closed set. Accepted green-300, progress sapphire-500, review sapphire wash, new neutral-dark, warning orange-400, danger red-400. New stages map to the six; counts go to Badge, filters to Chip.

    Reject: a seventh status hue — map, never invent.
