Components · Navigation · 01 Tabs

One row of views. Never a second dock.

Tabs switch views inside one context — pipeline stages, record sections, report slices. It selects a view; it never navigates pages. Use Tabs for peer views in place; use TabBar for the mobile dock, never both at once.

  • 01

    Anatomy — tablist · tab · panel. role=tablist holds role=tab triggers with aria-selected; each panel is role=tabpanel, hidden when inactive. Underline .tabs is default; .tabs--contained segments on --bg-interactive.

    Reject: a contained pill and an underline row for the same views — pick one chrome.

  • 02

    Scrollable, never squished. The tablist scrolls on overflow-x: auto and triggers hold white-space: nowrap. Narrow widths scroll the row; labels never shrink to fit.

    Reject: wrapped or truncated tab labels — overflow scrolls, it never wraps.

  • 03

    Roving tabindex, one stop. Exactly one tab carries tabindex="0", the rest -1; ArrowLeft/Right move, Home/End jump. Disabled tabs leave the roving order entirely.

    Reject: every tab in tab order — Tab enters once, arrows do the rest.
