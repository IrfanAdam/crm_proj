Components · Data · 06 FunnelGlyph

The measure mark. One tile everywhere.

FunnelGlyph is the funnel mark: a rounded sapphire tile with the glyph in bold display type. It marks measure-family visuals; it never celebrates. Use it when the funnel needs a face; use GemReward when something is won.

  • 01

    Anatomy — tile · glyph. Rounded tile plus glyph in bold display type; no label, no count, no chrome inside the tile.

    Reject: a glyph restyled per metric — one tile everywhere.

  • 02

    Sapphire means measure. Tile in sapphire-100 with sapphire-600 ink; the funnel never borrows a gem hue, however festive the metric feels.

    Reject: a gem-hued funnel — celebration hues never mark measure.

  • 03

    Sizes follow placement. 56px hero on cards, 40px small in strips and rows, 32px inline beside chips; radius steps down with the tile.

    Reject: a free-scaled tile — three sizes cover every placement.

Don't
