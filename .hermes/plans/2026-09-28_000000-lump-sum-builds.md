## Phase 1 — Pitch hero: light-defined gem floors, in-place retint, deployed type {#phase-1}

*Tags: Design System, Component*

### Task 1: Hero gem drop — the contact shadow lands on the headline's last line ✓ done

`GEM_SCENE.frame(rig)` re-aims the camera from stored base values (`baseCamY`/`baseLookY`) and
`rig.dropY` shifts the whole framed scene; `pitch-gem-cycle.js` measures the headline's bottom
against the shadow plane's live projection and solves the drop in two passes, so it converges
whatever the layout or font timing does. Zeroed on the stacked mobile hero. Hero and masthead
`max-width` 1160 → 1060 (the `.section` content column) and the headline clamp cap 4.4 → 4.2rem so
“Turn your sales” still fits the now-narrower copy column on one line.

**Verify:** shadow-plane centre = headline bottom ±1px at 1071/1200/1400/1500; hero x = section x = 220 at 1500; 3-line headline at every desktop width; 0 console errors.

### Task 2: Floors defined by the key light, caustics matched to the stone ✓ done

`GEM_BARE.dress()` now derives both floors from the scene's key directional (3,5,4): the contact
shadow lies opposite the key and is stretched on its ground azimuth; `GEM_BARE.aim()` re-places
both pools every frame from the stone's live height, yaw and pitch — the caustic pool turns 1:1
with the facets casting it (was −0.5×). The stone is a lens, so the dark pool stays near the
contact point while the cast light carries the offset; the bob dropped 0.045 → 0.03 and the plane
moved down so the culet can never cross the pool.

**Verify:** `caustic.rotation.z == group.rotation.y` mid-drag (3.84 = 3.84); `worldGap` 0.0425 at the bob minimum; pool centre 20px under the point at rest; clip reads a soft, subtle pool with no smear.

### Task 3: One stone, recoloured — variant switch without a remount ✓ done

New `GemReward/gem-tint.js`: `apply(canvas, name)` rewrites the mounted rig's material colours,
ior and spin and eases them over 1s (smootherstep); `step(rig, dt)` runs from the render loop, so a
drag in flight survives the change and the caustic map swaps once, at the end. The DS gallery's
gem-spec pills retint the live canvas too (the old canvas swap remains only as the no-module
fallback) — which is what that panel always claimed it did.

**Verify:** one canvas across an 8s window covering 3 variants; a 4.2s drag spanning a variant change keeps the same canvas and rotation; gallery reads `sameCanvas: true`, `218aea → ea005e`.

### Task 4: Mobile pass — gutters, edge bleed, tag height, pain-card footer ✓ done

The section/card mobile paddings moved behind `body …`, because the later sheets were winning the
cascade and leaving every section at 2rem instead of 1rem. Carousels bleed to the device width and
`scroll-padding-inline: 1rem` keeps the leading gutter after the mandatory snap (the snap was eating
it, so card 1 sat flush). Selected filter tags keep their height (✕ at `1em`, `line-height: 1`).
Pain cards: the severity dot moved from the title to a footer line with the lever tag, which is now
neutral subtext instead of reading as a fourth uppercase label.

**Verify:** 16px gutters at 390 (section/hero/masthead/footer/cards); card 0 and card 1 both at 16px after a snap; tags 23px before/after selection; clips.

### Task 5: The pitch renders its own type in a deployment ✓ done

Space Grotesk + DM Sans are self-hosted as variable woff2 in `public/fonts/` with
`src/pitch/pitch-fonts.css`; the `fonts.googleapis.com` link is gone. The pitch's
`--font-display`/`--font-body` moved off `:root` onto `body`: a build emits `tokens.css` *after* the
pitch bundle, so tokens' own `:root` values were silently winning in `dist/` while dev looked right.

**Verify:** the built page under `vite preview` reports both families loaded, only same-origin `/fonts/*.woff2` requests (0 CDN), headline line widths identical to dev (444/394), 0 console errors; `dist/fonts/*` present, 0 `googleapis` refs in `dist/pitch.html`.
