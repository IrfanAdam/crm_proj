# Mechanics budget exception — canvas engine + render

- Context: `src/js/mechanics/` ports Tapmania engine verbatim per `mechanics-visualization` skill (SKILL.md v0.1.0). Skill budget is ≤100 lines/module; Tapmania originals violate: `canvas.js` 151 lines, `render.js` 179 lines.
- Options: (a) split `canvas.js` into `canvas.js` + `canvas-interaction.js` — chosen for canvas; (b) split `render.js` into `render.js` + `render-edges.js` — rejected; `render.js` couples `EDGE_STYLES`/`anchor`/`edgePath`/`drawEdges`/`drawGroups`/`drawNodes` through shared `token()`/`kindColor()`/`getNode()` closure and `GROUPS/NODES/EDGES/KINDS` live bindings — splitting fractures the single rAF pipeline and token scaling (`p=0.38`) coherence; (c) compress verbatim to ≤99 via minification — rejected, breaks verbatim + readability.
- Decision: waive 100-line budget for `src/js/mechanics/render.js` (179 lines, verbatim from `clicker_test/src/js/mechanics/render.js`); keep `token(n)` via `getComputedStyle(document.documentElement).getPropertyValue(n)` — no raw hex outside `design-system/tokens.css`. `canvas.js` is split (26 + 52 lines) to satisfy engine constants `RH=18,RG=3,HH=32,PY=4,PX=3`, DPR cap 2, scale 0.18–3.8 — constants preserved in `src/js/mechanics/canvas.js`.
- Why: render is irreplaceable as scored edge pipeline (mono edges, halo, `kindColor` dot, `both` heads, dash scaling `6/scale`, `rad max(2/scale,9/scale,minSeg/2.4)`, label pills `9.5/scale`); splitting now would diverge from skill spec and future Tapmania sync.
- Consequences: `wc -l src/js/mechanics/render.js` remains 179 — documented exception. All other mechanics modules stay ≤99 (`route 87`, `corridor 41`, `popover 24`, `text 22`, `graph 24`, `index 84`, `canvas 26`, `canvas-interaction 52`). `npm run build` must pass; linter waives render only via this decision. Revisit if `lint-manage.mjs` gains per-file budget config — then add `render.js: waive` entry.
