Architecture — coming next

Portable app shell designed to move to any framework with zero redesign. Current shell is vanilla HTML/CSS/JS + React islands so the DS stays framework-agnostic.

  • Tokens: tokens/*.json → design-system/tokens.css (DTCG, npm run build) — single source, no raw hex
  • Glass: @samasante/liquid-glass <Glass> wraps DS chrome — style.background is color-mix(var(--bg-surface), transparent) + optics:{frost,dispersion,strength,depth,curvature,saturate} — live DOM refraction in Chrome, frost+tint elsewhere
  • Components: src/components/* — each ≤100 lines, var(--token) only, 44px tap, focus-ring
  • Patterns: src/patterns/* + src/logic/* (funnel machine, transient/temporal)
  • Prototype: app.html + app.css + src/glass/* — 393×852 iPhone 15 frame (19.5:9, 460ppi); app content is DS composition inside .device__content

Platform-specific tuning (blur strength, sheen, glow) can be done per OS later via optics — geometry stays 393×852.
